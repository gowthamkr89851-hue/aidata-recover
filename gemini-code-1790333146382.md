## 📋 1. Core Concept & Terminology Guide

**Aegis-Recover** solves two massive challenges: finding lost or deleted files from physical storage/devices (**Part 1**) and repairing, enhancing, and proving the authenticity of heavily corrupted or shredded digital evidence using AI (**Part 2**).

### Key Terminologies & Simple Examples:
* **File Carving (Magic Bytes):** Scanning raw binary data for unique file headers (called "magic bytes", e.g., `%PDF` or `FF D8 FF` for JPEGs) to un-delete files even when the file system index is wiped.
  * *Example:* Recovering a deleted invoice photo (`receipt.jpg`) from the raw unallocated sectors of a USB drive.
* **Fragment Stitching:** Reassembling torn, shredded, or scattered text/JSON chunks back into their correct sequential order using context-window logic.
  * *Example:* Taking fragmented server error logs that were scrambled during a crash and stitching them back into a chronological timeline.
* **Chain-of-Custody (SHA-256 Hash Chain):** A cryptographic audit trail where every single action (scanning, recovering, parsing) is locked into a tamper-proof hash ledger. If anyone alters the file, the hash changes instantly.
  * *Example:* Proving to judges in court or a jury that our tool never altered or falsified the recovered evidence.
* **Integrity & Confidence Scoring:** A mathematical percentage calculated by comparing missing fields vs. present fields in a recovered file.
  * *Example:* A restored database log gets flagged as `92% Complete (High Confidence)` vs. a heavily truncated text file marked at `41% (Partial Recovery)`.

## ⚙️ 2. The Two-Part System Workflow

### Part 1: The Live Disk & Device Digging Suite
1. **Source Selection:** The user launches the app and selects a storage target from a dropdown menu (Local SSD partition, attached USB pendrive, or a connected mobile/device backup dump).
2. **Deep Scan & Carving:** The backend parses partition tables and unallocated space to un-delete lost documents, images, and logs.
3. **Metadata Extraction:** Pulls original file names, file sizes, directory paths, and deletion timestamps.

### Part 2: The AI Corruption & Enhancement Engine
1. **Corrupted File Ingress:** A dedicated workspace where users drag and drop broken files (shredded JSON dumps, torn text logs, damaged archives).
2. **AI Data Repair & Enhancement:** The system automatically cleans up structural formatting, fills in minor missing keys contextually, and improves data readability.
3. **Immutable Audit Logging:** Every patch and recovery step is logged into the live SHA-256 audit drawer.
